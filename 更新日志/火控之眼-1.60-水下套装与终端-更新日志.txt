==================================================
一、声呐
==================================================
1. 新方块「声呐」：与火控计算机按火控学自身的方式连接——扳手右键火控计算机，
   再右键声呐；一台计算机可挂多台声呐，各自单独命名（界面里显示「声呐 <名字>」），
   接收范围、接收角度、俯仰角（上 / 下分开）都能单独设置，UI 的位置与比例也能调，
   多台声呐的画面可以同时显示。
2. 主 / 被动两种模式：被动只收声音；主动会发出回波，回波在别的雷达上持续显示并
   标记为「重」，同时会吸引监守者、触发幽匿传感器与尖啸体。
3. 振动分三级：生物与脚步为「轻」，Sable 结构移动、鱼雷游泳、履带与轮子为「中」，
   武器与火炮开火为「重」。越重的声源回声越大、颜色越深；原版放方块、开关门、
   钟声同样听得到。
4. 目标选择：可以在声呐设置里把输入绑成三种方式之一——无线频率 A / B（手持物品点击
   频率，和火控学自己的无线按钮一样）、普通遥控器、高级遥控器（点按钮后按遥控器上的
   键）。对着声呐画面按一下即锁定视线最近的声源，再对着同一个目标（或对着空水）按一下
   解除，对着别的目标按一下直接换目标、不用先解。锁定的声源在画面上带两条竖线，
   并标注「类别 + 距离」，大小随回声强弱变化。

==================================================
二、两种鱼雷
==================================================
1. 被动声自导鱼雷：入水后自动追踪听得到的最响目标（与声呐同一套声源）。没有目标时
   按设置巡航——水面巡航或定深悬浮；发射后要游出设置的「开机距离」才开始听。它不接收
   火控计算机锁定的目标，只拿巡航与开机距离这两项设置。
2. 线导鱼雷：发射瞬间锁定射线方向上的声源，全程只扑这一个、不再改口；声源静默后无法
   引导，鱼雷会自毁。
3. 两种鱼雷射程上限都是 60 秒燃料，且都必须装引信才会引爆。
4. 两种鱼雷都能被火控计算机接管，可由 CBCMS 鱼雷发射管、面包学鱼雷发射管，以及组装了
   发射管的炮座发射；每台火控计算机各存一份定深 / 开机距离设置，互不影响。
5. 威力对齐 CBCMS 平均水准：直击伤害 60 → 100，穿深 2 → 2.5（爆炸威力本来就高于
   CBCMS，未压回）。

==================================================
三、软杀伤鱼雷诱饵
==================================================
1. 新物品「软杀伤鱼雷诱饵」：由面包学的反步兵榴弹发射器装填发射，外观与面包学那颗
   榴弹完全一致；对着发射器右键一次上一发（满 6 档即满），附有装填与发射两行说明。
2. 落地 1 秒后开始每秒发一次「重」噪声，持续一分钟，落在哪里就在哪里响（不会跟着船跑），
   **全程不爆炸**。
3. 声自导鱼雷会循声扑来，监守者也会被引来；声呐（被动）上是一个深色的重标记。

==================================================
四、空投被动声自导鱼雷
==================================================
1. 新弹种：外观用视觉制导鱼雷那一套模型，手持右键**空的面包学挂架**即可装填，挂架、
   世界、手持三处外观都是视觉制导鱼雷。挂架上已有弹药时不能装。
2. 打出去之后入水行为与被动声自导鱼雷 100% 一致（追最响声源、无目标上浮待机、同一套
   听觉）。注意：要打船仍需**先给弹装引信**（放地上装引信→挖起来→上挂架，配件随弹走）。

==================================================
五、消音瓦（伪装方块三形态）
==================================================
1. 新增三种伪装方块：伪装薄板、伪装片、伪装半片（消音瓦），放在「火控之眼」功能页的
   水下部分分组里。
2. 消音效果：以振源为中心 3×3×3 内只要有一块瓦，该处声音就被吃掉——幽匿传感器、
   尖啸体、监守者与被动声呐全都听不到；被瓦贴住的地方放方块、开关门，幽匿系同样听不到。
3. 包住整个振源（外面糊一层）同样生效：走原版羊毛那套振动遮挡机制，六个轴向全被挡住
   才成立——只挡一面不算，这是预期行为。
4. 主动声呐：回波每穿过一层瓦，可探到的距离减半，最低降到八分之一；被动声呐则是
   路径上有瓦就完全听不到。
5. 与 copycats（伪装方块+）软依赖：没装 copycats 时三种瓦不进游戏、也不会崩；装了以后
   和 copycats 自己的伪装方块一样——放下是空壳，用复制方块材质右键贴材质才显示伪装外形。

==================================================
六、单兵声呐
==================================================
1. 新方块：水平四向放置，贴水放好后每 3 秒扫一次半径 50 格 / 90 度内的全部振动源并高亮。
2. 表现：会动的生物、弹药、鱼雷、导弹带**发光轮廓**（隔着地形也看得见，不给玩家本体画）；
   船壳画的是**整个形状的外轮廓线**（不是一格格的网格，也不是外面一个大方盒）；开火、
   机械这类没有实体的噪声画小方框，按轻 / 中 / 重上色。
3. 上限与性能：轮廓线段上限 12000 段，体积超过 64³ 的大结构退回整框；发光扫描 5 tick
   一次、船壳列表 10 tick 一次、多台单兵声呐的扫描相位错开，尽量避免同一 tick 一起扫。

==================================================
七、机载装订终端（打击终端）
==================================================
1. 新物品：右键一台火控计算机即绑定（会有成功 / 未绑定提示）；再次右键打开「航图」。
2. 航图里左键选点、右键清除标点、滚轮缩放；标点存在终端自己身上，下次打开还在。
3. 标点后按开火键：绑定的挂架弹药**直接打击这个定点**——原本需要吊舱锁定的挂架弹药，
   现在按标点投放。光电吊舱有锁时以吊舱为准；只有炸弹挂架 + 标点时会不等吊舱直接投放。
4. 航图优先画 Xaero 世界地图已经渲染过的地面（探索过的区域也有），Xaero 没画到的地方
   才退回本地已加载方块的采样画面。未安装 Xaero 时全部走本地采样，不影响使用。

==================================================
八、挂架交给火控计算机
==================================================
1. 炸弹挂架：面包学的炸弹挂架（含空挂架）现在能被火控计算机绑定，按空对地挂架计数与
   选择；投弹、下坠与爆炸仍然是面包学自己那套。挂架上的炸弹在雷达与自动反导画面上
   同样算作来袭弹药。
2. 巡航导弹挂架：高空款与低空款都能绑火控计算机。瞄准交给火控（光电 / 雷达锁定的地面
   点），**弹道、速度、寿命与爆炸仍遵守面包学原生**（约 5 格/tick、原生巡航爆炸），
   不会被火控拉成空对地导弹的速度与寿命。
3. 机载武器栏里，绑了巡航导弹挂架时会显示「巡航导弹」；如果旁边同时绑了普通空对地
   挂架，仍按「空对地导弹」显示。
4. 焊接结构上的挂架：出架的弹会落进结构自己的空间，已按新方式认领（认领不到的弹不会
   被沿航路保票，会卡在未加载区块）。

==================================================
九、涅瓦河超重型防空导弹
==================================================
1. 以**方块形式**直接放置：导弹本体即发射器，用火控计算机绑定该方块后直接锁定、发射，
   不需要额外装填。
2. 制导方式与火控原版高速防空导弹相同，末段额外补足横向过载：极速 2 马赫、过载 50G。
3. 战斗部威力是地面巡航导弹的 4 倍（48），高于重型防空导弹（36）。
4. 重型防空导弹同步调整：交由火控计算机与面包学垂直发射井使用，战斗部 36
   （地面巡航导弹 ×2），极速 3 马赫——补上火控自身防空制导 2 马赫的上限差距。

十三、参数调整与修复
==================================================
1. **语言文件失效**：上一轮把新增键追加到了闭合大括号之后，整份 `lang/*.json` 无效，
   进游戏后所有名称都变成 key。已并回主对象并重新校验；源码内全部 json 也全量校验过。
2. **架束弹拦不住慢速巡航导弹**：雷达把巡航弹速度报成被火控拉高后的值，提前量被算到
   目标前方上百格。修好弹道后读数恢复正常，并给速度低通滤波加了「读数突变就直接采信」，
   不再把错误速度平均十几 tick。
3. **炮射导弹毁伤对标大炮 HEAT**：直击 35 → 45、爆炸 6.0 → 8.0、喷射破片 45 → 60、
   喷射锥张角系数 0.03 → 0.01，四个毁伤维度全部不低于大炮 HEAT。
4. **巡航导弹在未加载区块停滞**：沿航路持票（脚下 24 格保持 ticking、前方 160 格只加载），
   并把「认领出架的弹」改走实体入世界事件，焊接结构上打出的弹也能被认领。
5. **消音瓦在结构上不生效**：Sable 结构的方块存在自己的空间里，旧实现在世界坐标上找瓦，
   永远找不到船壳上的瓦；现在按传入坐标与结构自身空间各查一遍，并把「路径遮挡」接上。

6. **非制导弹药投不出来**：面包学的炸弹挂架在「放空格架 → 绑火控计算机 → 用连接器装弹」之后，
   绑定会被判失效（空格架与已装弹挂架在火控眼里不是同一族），挂架随即从计算机上掉了，
   按开火只会提示「需要空对地锁定」。现在空格架与装弹后的挂架视为同一件，绑定不再丢；
   挂架也改成按坐标确认，焊接结构上的挂架一并兜住。普通炸弹（集束 / 中型 / 燃烧 / 小炸弹…）
   不再需要任何锁定即可投放；滑翔炸弹 / JDAM / 钻地弹仍需先在机载装订终端上标点。

十四、方块建模火炮炮管（玉诗方块建模）
==================================================
1. 装了「方块建模」（玉诗）后，建模的**实体方块**可以直接当火炮炮管用：在方块界面里选火炮类型
   —— 无 / 下界钢中型炮管 / 下界钢大炮炮管，与火控学自带的中型炮管合并成同一个按钮循环。
   选定后服务端**原地转换**该方块，建模数据与变换原样保留 —— 外观仍然是你自己搭的模型。
2. 炮管照抄真下界钢炮管的材质、铸造形状与开口，所以能和**同轴线的下界钢炮闩 / 药室**连接，
   也能在炮座上正常组装；它就是那根炮管，只是长什么样由你决定。
3. 炮口特效位置修正：机械动力火炮默认把开炮的烟火与冲击波放在炮口**后两格**，
   对"一格就代表整根炮管"的建模方块来说那正好落在炮尾，看起来像从屁股炸；
   现在改到该门炮**最前面那格建模炮管的炮口**上。
4. 没装方块建模时整条链路不加载（连它的类都不会碰），不影响正常运行。

十五、激光制导体系（吊舱照射 / 四联挂架 / 激光编码）
==================================================
1. 吊舱照射：光电吊舱照住的位置会成为面包学**原生激光弹药**的攻击点（光斑点由本模组按
   吊舱瞄准点投放，被地形/建筑挡住时不点亮）。
2. 激光弹跨区块：复用火控学自己的区块票机制，覆盖它全部 10 类激光弹；**光斑所在区块**
   也会在需要时保加载 —— 目标在未加载区域外也能接上。
3. 远距离：吊舱取点为空（目标在未加载区域内）时，沿「相机 + 吊舱朝向」自行计算最长
   1600 格的光斑；导引头搜索半径可配（`laserSeekerRange`，默认 3 倍 ≈1800 格，原为 600）。
4. 四联复合挂架（mixedrack / mixedracklasermissile_1..4 / …second_1..4）：现在可被
   火控计算机**绑定并发射**，档位显示为「激光制导导弹」；发射走它自己的程序，
   挂架状态逐发递减（4→3→2→1→空）。
5. 激光编码：每台计算机默认拥有**按坐标派生的唯一编码**，无需配置即互不干扰；
   也可在「火控设置」页底部手动填写（编码写进计算机本身）。两台计算机填同一编码
   即可「一架指示、另一架投弹」。备用命令：`/lasercode <0-9999>`。
6. 吊舱不再被锁定牵着走：弹药锁定不再参与决定吊舱看向哪里；吊舱视角内也不再获取
   弹药锁定（**炮镜那条链一行未动**）。
7. 移除本模组的雷达速度门（火控学已自带）：**功能与界面一并删除**（火控设置页里那两行控件
   已去掉，配置项不再读取），雷达不再按速度过滤接触。火控设置页底部新增/保留的
   **「激光编码」输入行**在最后一行（上方留一空行）。
8. 修复 5 处「运行时代码直接引用混入类」导致的初始化失败/崩服（方块实体类型访问器 4 处、
   女仆操作器 1 处），并清掉混入清单里已删混入的残留登记。
9. vestalihy 导弹连上火控计算机后**无法自动恢复**：补写恢复所需的参考标签，
   飞出计算机加载范围后能被自动接回继续制导。
10. （已移除）客户端激光点标记：试做后按玩家要求删除，激光制导本身不受影响。
11. 激光制导炸弹精度：光斑投放恢复为**每 tick 一个**（面包学导引头每 tick 采样，隔 tick 会丢一半
    制导更新，导致末端打偏）。
12. 设置界面适配所有分辨率：**声呐设置页、鱼雷设置页、目标选择绑定页**全部改为面板自适应
    （跑不出屏幕）、内容可滚动（滚轮 + 拖动滚动条）并做裁剪，小分辨率/大 GUI 缩放下不再卡住。
