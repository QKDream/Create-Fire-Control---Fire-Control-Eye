# 机械动力：先进火控：火控之眼

**Create: Fire Control — Fire Control Eye** · 版本 `1.1.0` · Minecraft `1.21.1` · NeoForge

为机械动力火炮·先进火控（`create-fire-control-0.7.0`）打造的弹药识别与火控增强扩展。它把 vestalihy、CBCMS、TAOV、面包学现代战争等模组的弹药统一接入先进火控的雷达体系，补齐光电锁定、TWS 多目标跟踪、目标标注、提前量指示，并带来架束近炸导弹与红外锁定导弹两款新弹种。

## 功能

### 雷达与反导
- **弹药识别**：vestalihy（PTUR / TOW / PTUR-JET / Malytka）、CBCMS（航空炸弹 / 鱼雷 / 火箭弹 / 深水炸弹 / 导弹）、TAOV（地狱火 / Tau）、面包学（导弹 / 火箭弹 / JDAM）全部进入显示连接器雷达与火控计算机雷达的扫描范围。
- **自动反导**：显示连接器的自动反导可对上述弹药做出反应并拦截。
- **火控计算机**：连接雷达后像扫描 Sable 结构一样扫出这些弹药，提供锁定框与导弹 / 火炮引导选项。

### 锁定与指示
- **目标类型标注**：锁定框下显示目标类型（`sable结构` / `弹药` / `生物`），由服务端下发，远距离弹药不会误标；地面雷达锁定后同时显示目标相对速度。
- **TWS 多目标跟踪**：机载与地面雷达同时跟踪多个目标；锁定目标额外套一圈方框，其余目标框保持不丢；第三人称视角同样可见。
- **光电锁定弹药**：光电吊舱可锁住飞行中的弹药；光电 / 雷达双锁时只显示一份文字，互不覆盖。
- **提前量指示**：锁定框中心沿预测命中点画出指示线，末端为小圆环，长度随目标速度与距离变化；用机炮对准圆环开火即可命中。
- **空空导弹近炸**：空空导弹锁定实体弹药 / Shaolib 弹体时，近炸引信按弹药实际位置正常触发。

### 武器与联动
- **显示连接器手动指示**：连接双机炮座 / 防空导弹发射器后，无需开启自动攻击，即可在显示连接器上手动指示目标带动双机瞄准。
- **地狱火引导器**：适配先进火控头瞄系统，用法与面包学激光瞄准器一致。
- **TAOV 机炮兼容**：TAOV 武器库的机炮可像完整组装的 CBC 火炮一样绑定到火控计算机与连接显示器。
- **机炮革命弹药兼容**：TAOV 机炮可正常发射机炮革命与 CBCMW 弹药，并保留对应弹种特性。

### 制导导弹（新增）
- **架束近炸导弹**：可装填于反坦克导弹发射器与防空导弹发射器，制导方式为半自动指令线，跟随激光制导器光束飞行，激光指向即命中点；对 Sable 结构、面包军火库 / CBCMS / TAOV 弹药近炸（近炸半径 10 格）；5 秒加速，极速 680 格/秒，过载 30G。
- **地面型·红外锁定导弹**：装填于防空导弹发射器，无需锁定即可发射；发射后自动在正前方 60° 锥形范围内索敌并追踪 Sable 结构、面包学导弹、TAOV 导弹、vestalihy 导弹、CBCMS 炸弹 / 火箭弹 / 鱼雷以及面包学干扰弹。最大速度 1 马赫，过载 25G，带 5 秒加速段。
- **空射型·空射红外弹**：挂载于机载武器挂架，接火控计算机时机载武器选择显示为「空射红外弹」，其余性能与地面型一致。
- **索敌范围框**：发射前显示与 60° 搜索锥对应的红色角框，方向为导弹发射方向；地面型仅炮镜视角显示，机载型仅在选择红外弹时显示。
- **目标红框**：坐在绑定火控的座椅上时，可用红色方形锁定框看到导弹当前锁定的目标。
- **全距离尾焰**：转弯时尾焰严格沿真实弹道绘制，不再出现直线幽灵火光。

## 安装要求（Minecraft 1.21.1 · NeoForge）

按以下顺序放入 `mods` 文件夹（本 mod 最后放）：

1. `create-1.21.1-6.0.10.jar`（机械动力）
2. `create-fire-control-0.7.0.jar`（机械动力火炮：先进火控）
3. `createbigcannons`（机械动力火炮）
4. `sable-neoforge-1.21.1-2.0.5.jar`（结构子系统）
5. `mianbaos_modernwarfare-2.5.0-neoforge.jar`（面包学现代战争）
6. `taov_core-0.1.0.jar` + `taov_weapons-0.1.1.jar` + `shaolib-0.1.0.jar` + `shaolib_munitions-0.1.0.jar` + `synaxis-1.5.0.jar`（TAOV 武器）
7. `vestalihy-2.5.3.jar`（维斯太利弹药）
8. `[机械动力火炮：武器拓展] CBC-Military-Supplement-1.21.1-2.1.4.jar`（CBCMS）
9. 本 mod：`firecontrolcompat-1.1.0.jar`

## 使用方法

1. 把 `firecontrolcompat-1.1.0.jar` 放入 `mods` 文件夹，启动游戏。
2. 搭建显示连接器 + 雷达，打开「自动反导」与「导弹扫描」。
3. 从敌对方向发射 / 投掷上述弹药，雷达屏幕会将其显示为导弹目标并被自动拦截。
4. 火控计算机连接雷达后，雷达页面会出现这些弹药的联系人；锁定后即可使用防空导弹或火炮引导。
5. 观察锁定框下方的类型 / 速度文字与提前量圆环，机炮对准圆环开火。
6. 防空导弹发射器装填「架束近炸导弹」并用激光制导器持续照射目标，导弹沿光束飞行并对目标近炸。
7. 防空导弹发射器装填「红外锁定导弹」、机载挂架选择「空射红外弹」，无需锁定直接发射即可自动索敌。

## 构建

`build.ps1` 会从本机 `.minecraft` 目录自动收集 Minecraft / NeoForge / 各模组的 jar 作为编译类路径，然后编译并打包 `firecontrolcompat-1.1.0.jar`。构建需要 Windows 与 Java 21 运行环境。
